## Overview
This project analyzes restaurant sales data using Python to identify sales trends, customer preferences, and business performance. The analysis includes data cleaning, exploratory data analysis (EDA), revenue calculation, and visualization.

## Objectives
- Analyze sales performance and revenue trends
- Identify top-selling and highest-revenue products
- Understand customer payment preferences
- Evaluate manager and city performance
- Compare monthly revenue performance

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Findings
- Credit Card was the most preferred payment method (47.2% of transactions).
- Beverages had the highest sales quantity.
- Burgers generated the highest revenue ($376,658).
- Lisbon was the top-performing city by revenue.
- Joao Silva achieved the highest revenue among managers.
- December recorded higher average revenue than November.

## Dataset
The dataset contains restaurant transaction records, including:
- Order ID
- Date
- Product
- Price
- Quantity
- Purchase Type
- Payment Method
- Manager
- City
